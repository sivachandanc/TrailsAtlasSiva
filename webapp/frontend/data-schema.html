Member data the filters expect

The SQL from every filter step (Databricks / Spark SQL) runs against these tables. Only the columns the filters read are listed; your tables can have more. Table names can be changed in .env (MEMBERS_TABLE, MX_CLAIMS_TABLE, RX_CLAIMS_TABLE). Trails-POC never reads or stores member data; this page only describes the shape.
